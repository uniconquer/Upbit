# 반복 모의매매와 자동 후보 개선

이 기능은 신경망 강화학습이나 Codex 모델 재학습이 아니다. **진화형 설정 탐색과
미래 모의 성과를 이용한 후보 선택**이다. 성공한 설정도 다음 시장에서 손실을 볼 수 있고,
관찰을 오래 한다고 성능이 반드시 좋아지는 것은 아니다.

## 반복 과정

1. 같은 공개 현재가와 완료 일봉을 24개 후보에 전달한다.
2. 후보마다 가상 10만 원으로 기본 비용과 높은 비용의 두 계좌를 따로 유지한다.
3. 매시간 최대 한 번 관찰한다. 동일 시간대 재실행은 거래·관찰 수를 늘리지 않는다.
4. 최소 30일, 관찰 날짜 25일, 기대 시간대 대비 관찰률 80%가 쌓이면 세대를 평가한다.
5. 대표 후보 교체에는 완료 매도 10회 이상, 두 비용 조건 모두 양의 수익, 최대낙폭
   20% 이내, 중단되지 않은 상태, 기존 대표/현금 점수보다 1점 이상 높은 점수를 요구한다.
6. 상위 설정을 보존하고 진입 계열·기간·ATR 배수·위험 비중을 변형해 다음 후보를 만든다.
   새 후보는 새 관찰부터 평가하며 과거 수익을 물려받지 않는다.

점수는 `100 × log(평가액 / 초기자금) − 0.5 × 최대낙폭 크기(%)`다.
이는 빠른 복리 성장과 손실을 함께 고려하는 연구용 기준이며 통계적 유의성 검정은 아니다.
여러 후보를 반복 비교하므로 우연한 승자가 생길 수 있다. 교체 기록은 모의 실험 안의
대표 설정 선정이며, 실제 계좌나 기존 단일 프로필 모의계좌를 교체하지 않는다.

첫 대표는 현금/검증 대기다. 모든 후보가 실패해도 강제로 매매 전략을 대표로 만들지 않는다.
기존 대표가 다음 성숙한 세대에서 음의 점수 또는 중단 상태이면 현금으로 돌아간다.

## 넓힌 가상 실험 범위

기존 16개 후보 외에 투자 비중 100%, 종목 비중 100%, 거래 위험 예산 3%,
일·누적 손실 중단선을 100%로 둔 공격적인 가상 후보 8개를 추가했다.
다음 세대의 위험 예산은 0.75%·1.5%·3%·5%, 전체 투자 비중은 60%·80%·100%에서 탐색한다.
따라서 실제로 파산에 가까운 손실이 생길 수 있으며 그런 결과도 기록에 남는다.

현금보다 더 매수하거나, 수수료·슬리피지·최소 주문금액을 없애지는 않는다.
손실이 난 계좌에 가상 돈을 중간 주입하지 않는다. 세대가 바뀔 때는 공정한 비교를 위해
모든 새 후보를 같은 초기자금으로 시작하되, 이전 세대의 포지션·거래·손실을 통째로 보존한다.
서로 다른 세대의 잔액은 하나의 계좌 수익 곡선으로 합산하면 안 된다.

## 실제 관찰과 한계

- 일봉 기반 전략이다. 초단타 체결이나 호가창 대응을 구현한 것이 아니다.
- 현재가를 관찰할 때만 모의 체결한다. 관찰 사이에 닿은 손절가를 소급 체결하지 않는다.
- 기본 및 높은 비용 계좌는 같은 관찰 시세를 받는다.
- 잠금과 원자적 파일 저장을 사용한다. 프로세스 실패 전 미저장 변경은 폐기된다.
- 세대 평가에 과거 백테스트를 새 미래 성과인 것처럼 넣지 않는다.
- 실거래 API·계좌 키·환경변수·기존 워커 설정을 사용하거나 바꾸지 않는다.

## 실행과 확인

```powershell
py -3 -m src.paper_learning
```

`적응형 모의매매` 메뉴의 **자동 개선 실험**에서 세대, 후보별 평가액, 높은 비용 수익률,
관찰률과 대표 교체 기록을 볼 수 있다. **학습 관찰 1회** 버튼도 같은 명령과 동일한 경로를 쓴다.
기록은 `.runtime/paper-learning/state.json`에 저장되며 `archive`에 이전 세대 전체를 보존한다.
저장 파일은 시간이 지나면 커지므로 장기 운영에서는 별도 백업·보관 정책이 필요하다.

매시간 실행은 이 작업에 연결된 예약 작업으로 설정한다. 로컬 폴더를 쓰므로 컴퓨터가 켜져
있고 앱이 실행 중이어야 한다. 앱이나 PC가 꺼지면 관찰이 누락되며, 관찰률이 부족한 동안
새 세대 평가·대표 승격은 진행하지 않는다.
[예약 작업 공식 안내](https://learn.chatgpt.com/docs/automations?surface=app).

첫 실행은 2026-09-06 UTC에 24개 후보로 시작했으며 대표 승격은 없었다.
수익성이 입증됐다는 의미가 아니다. 기존 연구의 실전 판정 `RESEARCH_ONLY`도 유지된다.

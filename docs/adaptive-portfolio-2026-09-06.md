# 적응형 포트폴리오 연구·모의매매 — 2026-09-06

## 현재 판단

새 포트폴오 전략리, 공통 모의체결 엔진, 순차 검증 도구, 현재 시세 모의매매,
Streamlit의 **적응형 모의매매** 메뉴를 구현했다. 실제 주문·환경변수·실행 중인 기존
워커는 변경하지 않았다. 초기자금 100,000원은 가상자금이며 실제 입금액을 읽지 않는다.

16개 후보로 확장한 개발 구간의 순차 수익률은 +10.08%였으나, 마지막 400일은
-2.50%였다. 현재 상태는 **RESEARCH_ONLY**이며 실전 투입 기준을 충족하지 못했다.
개발 구간 개선만으로 수익성 또는 이전 전략에 대한 전반적인 우월성을 주장하지 않는다.

## 전략

1. BTC 종가가 200일 EMA보다 높고 EMA가 상승할 때만 신규 매수를 고려한다.
2. 개별 종목도 상승 추세와 양의 중기 모멘텀을 만족해야 한다.
3. 진입 후보는 세 계열이다: 최근 고점 돌파, 추세 확인 후 진입, 상승 중 눌림목 반등.
4. 20·60·120일 모멘텀을 ATR 비율로 나눈 점수로 매수 우선순위를 정한다.
5. 종가에 확정된 조건을 다음 봉 시가에 적용한다. 실시간 모의매매에서는 관찰 시점의
   현재가를 사용하므로 과거 재생과 체결가격은 다를 수 있다.
6. ATR 손절과 추세 이탈 청산을 적용한다. 손절선은 이전 완료 봉으로만 올리며 내리지 않는다.

거래 횟수를 목표로 늘리지 않는다. 매수 조건이나 선택 점수가 불리하면 현금을 유지한다.
BTC·ETH·XRP는 연구 대상으로 고정했으며 전체 업비트 시장의 성과를 대표하지 않는다.

## 가상자금의 제한

| 항목 | 설정 |
|---|---:|
| 초기자금 | 100,000원 |
| 거래당 손절 예상 위험 예산 | 현재 평가액의 0.75% |
| 종목당 최대 투자 | 40% |
| 전체 최대 투자 | 60% |
| 최대 보유 | 2종목 |
| 일 손실 신규 매수 중단 | 2% |
| 자산 최고점 대비 신규 매수 중단 | 10% |
| 최소 주문대금 | 5,000원 |
| 편도 수수료 가정 | 0.05% |
| 편도 슬리피지 가정 | 0.10%, 스트레스 0.30% |

위험 예산은 손절가에서 체결된다는 가정의 예상 손실이다. 급락 시 실제 손실 상한이 아니다.
가격이 손절선을 건너뛰면 더 불리한 관찰 가격으로 체결한다. 손절 중단선에 도달해도
보유 포지션의 청산 판단은 계속한다. 10% 중단 상태는 재시작·날짜 변경으로 해제되지 않는다.
최소 금액 미만의 청산은 실패로 기록하고 포지션을 유지한다.
KRW 최소 금액 근거: [업비트 공식 안내](https://docs.upbit.com/kr/docs/krw-market-info).
수수료와 슬리피지는 계정 조회값이 아닌 실험 가정이다.

## 실험 기록

각 종목 2,400개 완료 일봉을 사용했다. 후보 선택은 직전 540일, 다음 검증 구간은 180일이다.
선택 함수에는 다음 구간 데이터를 전달하지 않는다. 6개 구간의 순차 검증 후
별도의 마지막 400일을 평가했다. 후보 점수는 수익률에서 최대낙폭 크기를 뺀 값이며,
학습 완료 거래가 5회 미만이거나 양의 점수가 없으면 현금을 선택한다.

- V1: 돌파 방식의 추세 기간·돌파 기간·ATR 배수 조합 8개.
- V2: 추세 진입 및 눌림목 계열을 추가한 16개. 후보와 데이터 해시를 저장했다.
- V2의 개발 기간을 보고 계열을 확장했으므로 그 개발 성과도 완전히 미지의 성과는 아니다.
- 마지막 기간은 이전 실험에서도 이미 본 날짜다. **독립적인 최종 검증이라고 부르지 않는다.**
  미래 모의매매 기록이 별도로 필요하다.

| 실험 | 개발 순차 수익률 | 개발 최대낙폭 | 마지막 400일 수익률 | 마지막 최대낙폭 |
|---|---:|---:|---:|---:|
| V1, 8개 후보 | +2.28% | -2.86% | -2.50% | -3.86% |
| V2, 16개 후보 | +10.08% | -4.17% | -2.50% | -3.86% |

V2 개발 기간: 2022-08-18 ~ 2025-08-01 UTC. 완료 거래 20회, 양의 수익 3/6구간.
마지막 기간: 2025-08-02 ~ 2026-09-05 UTC. 완료 거래 8회, 승률 25%,
가상자산 97,495.92원. 비용 스트레스에서는 -2.70%.
같은 위험 관리 엔진의 고정 기본 설정은 마지막 기간 -3.25%, 최대낙폭 -5.14%였다.

순차 검증 구간 경계에서는 순청산 추정액으로 현금화하고 위험 기준점을 초기화했다.
실제 미래 모의매매는 상태를 계속 유지한다. 경계 청산 추정은 최소금액 미만 잔여분을
완벽하게 재현하지 않으므로 구간 연결 성과에 이 한계가 있다.

## 미래 모의매매 프로필

마지막 평가 시작일의 설정을 오늘 설정으로 재사용하지 않는다. 2026-09-05까지의
최신 540일에서 다시 선택해 `paper-profile.json`으로 고정했다.
선택은 돌파 방식, 추세 120일, 돌파 10일, 손절 3.5 ATR이다.
해당 선택 구간 성과 +3.42%는 **학습 성과**이며 미래 실적이 아니다.

새 프로필로 현재 공개 시세를 2회 관찰했다. 신규 매매 0건, 가상 현금 100,000원이다.
두 번의 무체결 관찰은 수익성 검증이 아니다. 손절·비용·재시작·체결 동작은 별도
결정론적 테스트와 과거 재생으로 검증했다.

현재 시세 관찰은 키를 읽거나 주문 API를 호출하지 않는다. 오래되거나 누락된 가격은
거부하며, 프로필·보유 상태는 파일 잠금과 원자적 저장으로 보호한다. 동일 날짜 신호는
재시작 후에도 재주문하지 않는다. 기존 보유와 손절 판단은 매 관찰 때 확인한다.

## 사용

기존 Streamlit을 다시 실행하거나 새로고침하고 **적응형 모의매매** 메뉴를 선택한다.
`현재 시세로 모의매매 1회` 버튼은 누를 때만 관찰한다. 계속 켜진 감시 작업을 자동으로
설치하지 않았으며, 아래 CLI도 지정 횟수 후 종료한다.

```powershell
# 현재 프로필로 1회 모의 관찰
py -3 -m src.portfolio_paper

# 60초마다 총 60회 관찰 후 종료
py -3 -m src.portfolio_paper --cycles 60 --interval 60

# 저장한 시세로 결과 재현; 기존 실험 파일을 보존하도록 새 출력 폴더 사용
py -3 -m src.portfolio_research --expanded --input-dir .runtime/portfolio-research-v2 --output .runtime/portfolio-replay
```

관찰 사이에는 손절을 실행할 수 없고, 재시작 시 누락 시간대의 과거 가격으로 소급 체결하지 않는다.
프로필을 교체할 때는 기존 기록을 보존하도록 새 `--state` 경로를 사용해야 한다.

## 코드 및 산출물

- `src/adaptive_portfolio.py`: 완료 봉 지표, 위험 예산, 공통 모의매매 상태, 일봉 재생.
- `src/portfolio_research.py`: 후보 비교, 순차 실험, 최신 미래 프로필 선택.
- `src/portfolio_paper.py`: 공개 현재가 관찰, 파일 잠금·저장·재시작.
- `src/views/portfolio_view.py`: 결과·자산곡선·미래 모의매매 화면.
- `.runtime/portfolio-research-v1/`, `.runtime/portfolio-research-v2/`: 프로토콜·원본 CSV·결과.
- `.runtime/adaptive-paper-v2/state.json`: 최신 프로필의 미래 관찰 기록.

실전 경로에 새 전략을 넣지는 않았다. 기존 스캐너와 이 포트폴리오는 종목·자금 관리 방식이
다르다. 실제 호가·부분체결·네트워크 장애·급락·최소 수량과 주문 정책은 향후 통합 검증 대상이다.
현재 결론은 “프로그램과 연구 경로는 구현했고, 수익성 입증은 아직 부족하다”이다.
